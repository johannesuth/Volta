# Security Policy

Copyright © 2026 Johannes Uth.

## Supported versions

The latest stable Volta release is supported. Older releases may not receive
security fixes; update to the latest signed and notarized release when one is
available.

## Reporting a vulnerability

Please do not publish vulnerability details in a public issue. Use GitHub's
private vulnerability reporting from the repository's **Security** tab. The
repository owner should enable private reporting after creating the GitHub
repository. If that channel is unavailable, contact Johannes Uth privately via
the GitHub profile associated with `johannesuth` and include only the minimum
reproduction details needed.

Do not attach raw power logs, diagnostic archives, serial numbers, credentials,
or other personal data unless they have been reviewed and redacted.
